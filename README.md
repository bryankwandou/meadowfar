# Meadowfar

Dunia terbuka 3D untuk anak-anak yang berjalan langsung di peramban. Tanpa unduhan, tanpa iklan, tanpa pembelian dalam permainan.

## Apa isinya

- Peta prosedural tanpa batas: bukit, pohon, bunga, dan batu tumbuh mengikuti arah jalan pemain, chunk demi chunk.
- Misi yang lahir terus-menerus: kumpulkan bintang emas, buah beri, kristal biru, dan seterusnya tanpa ada tamat.
- Dua tokoh pilihan (anak perempuan dan anak laki-laki), dibangun murni dari geometri Three.js — nol aset berhak cipta.
- Kontrol keyboard (WASD atau panah) dan tuas sentuh untuk HP dan tablet.

## Menjalankan lokal

```bash
npm install
npm run dev
```

Buka http://localhost:3000 untuk landing page, dan /play untuk masuk ke dunianya.

## Teknologi

Next.js (App Router), Three.js, Tailwind CSS. Semua aset dunia dibuat dari kode.
